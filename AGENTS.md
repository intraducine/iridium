# Repository work rules

Read CONTRIBUTING.md before changing this monorepo. Read component instructions
and license notices for each touched directory. The same review and evidence
rules apply to generated code and human code.

Preserve unrelated work and uninitialized submodules. Stage only intended files.
Do not modify runtime behavior while working on publication infrastructure.
Do not build, install, sign, tag, or publish without authorization for that action.
Keep Actions builds manual. Never access or upload personal signing material.
Report exactly what was tested and what remains blocked; do not equate a build
with device compatibility. Use docs/releasing.md for every release description.
