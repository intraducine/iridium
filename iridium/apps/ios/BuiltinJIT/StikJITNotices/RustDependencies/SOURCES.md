# Rust standard-library dependency notices

These unchanged upstream notices come from checksum-verified registry archives
in Rust 1.98.1's library/Cargo.lock. The matching library source and toolchain
commit record are included in the corresponding-source package. This directory
supplements the Rust copyright inventory; it does not replace file-level grants.

Source packaging includes all 30 locked registry crates, including non-iPhone
platform dependencies. Inclusion in that lockfile is not proof of final linkage.
The full source archives preserve embedded notices even where there is no
standalone license file. `notice-files.json` records the copied notice hashes.
