# Media library notices

These upstream texts come unchanged from the source archives inside the retained
Cerbero 1.28.6 source bundle. Cerbero revision:
`59548269f4fd0f701818f0bafdb102959ec81e65`.
The original bundle SHA-256 is
`2429f050f96a35485e24b92dac2f9e0fde7492f34f3da680d1c2288f802df94d`.
The source package includes the recipes, source archives and local patches.
`notice-files.json` records the exact notice bytes.

The component directories name the source versions. FFmpeg's full upstream
license explanation and license alternatives are preserved. The pinned recipe
uses its Meson port with GPL, version3 and nonfree options disabled; retaining
upstream GPL texts does not mean those optional files were compiled.

These notices cover the C/C++ media components found in the app-registration
link probe. MoltenVK notices are in the adjacent MoltenVK directory. Media Rust
runtime notices are in the adjacent MediaRust directory. The final app link
inventory remains a separate release check. This file does not assert playback support for any game.
