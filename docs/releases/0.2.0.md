# Iridium 0.2.0

Download and repair Steam games in Iridium and use the updated Windows runtime.

## Download

[Download Iridium (.ipa)](https://github.com/intraducine/iridium/releases/download/v0.2.0/Iridium-unsigned.ipa).
Requires iOS or iPadOS 18 or later, JIT, and games you own.

## Install

1. Sign and install the app and helper with a compatible sideloading tool, or
   import the IPA into LiveContainer and use its JIT setup.
2. Open **Launch Support** and set up JIT. For a standalone install, the signing
   profile and final signature must include the increased memory entitlement.
3. Open **Downloads → Steam** to download an owned game, or **Add Game** to
   import a game folder. Choose the game from your library and press **Play**.

Back up your saves before updating. Install over your existing copy to keep its
data.

## What's new

- Steam sign-in and a download queue with pause, resume, verification, and repair.
- Storage warnings before downloads begin.
- Updated 32-bit Windows game support, Direct3D 9, and Direct3D 12.
- Support for running EXE and MSI installers from **Game Options**.

## Known issues

- Keep Iridium open while downloading. Resume downloads if the app goes into
  the background.
- Game compatibility varies by device and signing setup. A game that downloads
  successfully may still fail to run.
- Repairs and updates can keep older game folders. This needs extra storage.
  Check that your saves work before deleting an older copy. If the game stored
  its saves there, you may need to copy them manually.
