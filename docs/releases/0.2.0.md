# Iridium 0.2.0

Download your Steam games directly in Iridium, manage repairs and updates, and try the updated Windows runtime. Game support remains experimental.

## Download

**Release preparation draft: the 0.2.0 IPA has not been built or published.**

Planned download: **[Iridium (.ipa)](https://github.com/intraducine/iridium/releases/download/v0.2.0/Iridium-unsigned.ipa)**. This link becomes available only after publication.

Requires **iOS or iPadOS 18+**, JIT, and games you own. You only need the IPA to install; supply your own game files or download owned games from Steam.

## Install

1. Once the release is available, sign and install the IPA with a compatible sideloading tool, including its helper extension, or import it into LiveContainer.
2. Open Iridium and configure JIT in **Launch Support**.
3. Open **Downloads → Steam** to sign in and queue a game, or use **Add Game** to import a game folder. Choose its executable, add it to your library, then press **Play**.

Back up your saves before updating. Update the existing app or LiveContainer entry without deleting its data. Steam repairs and updates keep older installations; saves stored inside an older game folder may need to be copied manually to the new one. Keep that older folder until you have checked your saves.

## What's new

- **Steam downloads in the app.** Sign in with a password or QR code, with Steam Guard support, browse your library, and choose download language, branch, 32/64-bit files, and owned DLC.
- **A download queue with verification and repair.** Pause, resume, retry, and prioritize downloads. Check for updates or repair downloaded files while keeping the previous installation.
- **Clearer storage warnings.** Download checks use the space available to Iridium and account for verified partial files. **Download Anyway** can bypass an estimated-space warning for one attempt; file verification and real out-of-space errors remain enforced.
- **Updated Windows runtime.** Includes 32-bit WoW64 support and D3D9/D3D12 updates. Support still varies by game and device.
- **Game prerequisite installers.** Run setup steps included with a game, or choose **Game Options → Run Installer** for an EXE or MSI installer you provide.
- **Smaller IPA packaging.** Identical Windows runtime files share one packaged copy.

## Known issues

- Physical-device compatibility for these changes has not been established. Some games may fail to launch or have graphics, video, audio, input, save, or shutdown problems. Skyrim speech and mouse attack issues remain unverified.
- Keep Iridium open while downloading. Downloads pause when the app goes into the background and need to be resumed. Real-account downloads and recovery after Wi-Fi or network loss still need device testing.
- Steam Cloud, Workshop, Steam Families library discovery, password-protected branches, and desktop Steam services are not included. Games that require Steamworks/DRM, anti-cheat, or other unsupported runtime features may not launch after downloading.
- Updates keep older game copies and need extra storage. **Download Anyway** does not create free space; exhausting device storage can also prevent other apps from saving.
- JIT and available memory depend on your device and signing setup; LiveContainer and standalone results can differ. Prerequisite installer success is game-dependent.
