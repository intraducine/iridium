# Iridium 0.2.0

Release draft. The evidence below is from the earlier 0.1.1 integration baseline.

## Download

Planned asset: `Iridium-unsigned.ipa`. No 0.2.0 release artifact is identified here.
Requires iOS/iPadOS 18+, JIT, and owned games.

## Install

Sign the app and helper or use LiveContainer. Configure Launch Support, then
import a game or select Steam. Back up saves and keep existing app data.
Preserve increased-memory-limit in the final signature/profile; the anonymous
carrier alone grants no provisioning rights.

## What's new

- Native Steam sign-in, verified downloads, queue, repairs, and updates.
- Storage warnings and one-attempt Download Anyway.
- WoW64, D3D9/D3D12 updates, and game prerequisite installers.

## Known issues

Device compatibility and real-account downloads were not established by the
baseline. Its downloads require foreground use. Cloud, Workshop, Families,
protected branches, and desktop Steam services are outside this draft's scope.
Keep older game copies until saves work after an update.
