# Iridium 0.1.0

Play your Windows games on iPhone and iPad. This first release is experimental; game compatibility varies.

## Download

**[Download Iridium (.ipa)](https://github.com/intraducine/iridium/releases/download/v0.1.0/Iridium-unsigned.ipa)**

Requires **iOS or iPadOS 18+**, JIT, and your own game files. You only need the IPA to install.

## Install

1. Sign and install the IPA with a compatible sideloading tool, including its helper extension, or import it into LiveContainer.
2. Open Iridium and configure JIT in **Launch Support**.
3. Select **Add Game**, choose your game folder and executable, then press **Play**.

Updating a development build? Back up your saves and update the existing app or LiveContainer entry without deleting its data.

## What's new

- A game library with artwork, Favorites, and search.
- On-screen controls, controller support, and keyboard/mouse input.
- Game Options, launch logs, and performance controls.
- The updated Madeira runtime, plus keyboard, artwork, and save-path fixes.

## Known issues

- Some games may fail to launch or have graphics, video, audio, or input problems.
- Skyrim speech and mouse attack issues remain unverified in this build.
- JIT and available memory depend on your device and signing setup; LiveContainer and standalone results can differ.

## Source and licenses

The remaining assets are for source access, rebuilding, and download verification:

- Both `Iridium-corresponding-source.tar.gz.part01` and `.part02` contain the complete matching source package.
- `Iridium-source-guide.zip` contains license notices and build/relink instructions.
- `SHA256SUMS` verifies the four downloadable files above, including the IPA.

Download all five assets into one folder, then run:

```sh
shasum -a 256 -c SHA256SUMS
cat Iridium-corresponding-source.tar.gz.part01 Iridium-corresponding-source.tar.gz.part02 > Iridium-corresponding-source.tar.gz
```
