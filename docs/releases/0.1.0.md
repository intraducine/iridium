# Iridium 0.1.0

Experimental Windows game support for iPhone and iPad.

## Download

[Download the IPA](https://github.com/intraducine/iridium/releases/download/v0.1.0/Iridium-unsigned.ipa).
Requires iOS/iPadOS 18+, JIT, and your own game files.

## Install

1. Sign/install the app and helper, or import into LiveContainer.
2. Configure **Launch Support**, then **Add Game** and select the executable.
3. Select **Play**. Back up saves before updating; keep existing app data.

## What's new

- Artwork library, Favorites, and search.
- Touch controls, controllers, keyboard/mouse, and player settings.
- Madeira runtime integration and artwork/save-path fixes.

## Known issues

Compatibility varies. Graphics, media, audio, and input faults remain possible.
Skyrim speech/mouse attack is unverified. JIT and memory depend on signing and hosting.

## Source and licenses

Download both source parts, `Iridium-source-guide.zip`, and `SHA256SUMS` beside
the IPA. The guide contains notices, the assembled hash, and rebuild instructions.
The automatic GitHub ZIP lacks required dependencies.

```sh
shasum -a 256 -c SHA256SUMS
cat Iridium-corresponding-source.tar.gz.part01 Iridium-corresponding-source.tar.gz.part02 > Iridium-corresponding-source.tar.gz
```
