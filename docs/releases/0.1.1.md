# Iridium 0.1.1

In standalone Iridium, you can now add games from its folder in Files without opening the file picker. This release also makes it easier to import a pairing file for built-in JIT. Game support remains experimental.

## Download

**[Download Iridium (.ipa)](https://github.com/intraducine/iridium/releases/download/v0.1.1/Iridium-unsigned.ipa)**

Requires **iOS or iPadOS 18+**, JIT, and your own game files. You only need the IPA to install.

## Install

1. Sign and install the IPA with a compatible sideloading tool, including its helper extension, or import it into LiveContainer.
2. Open Iridium and configure JIT in **Launch Support**.
3. Select **Add Game**, choose a game folder and executable, then press **Play**.

Back up your saves before updating. Update the existing app or LiveContainer entry without deleting its data.

## What's new

- **Add games without the file picker.** In standalone Iridium, put each game in its own folder under **On My iPhone/iPad → Iridium → Games**. Choose **Add Game → Find Games in Iridium Folder**, select the game, and confirm its executable. Iridium uses the files in that folder without copying them.
- **Import a JIT pairing file from Files.** Put `pairingFile.plist` under **On My iPhone/iPad → Iridium → StikJIT**. Choose **Settings → Launch Support → Import Pairing File → Use File in Iridium Folder**. You can still choose a file directly.

## Known issues

- Some games may fail to launch or have graphics, video, audio, or input problems.
- Skyrim speech and mouse attack issues remain unverified in this build.
- JIT and available memory depend on your device and signing setup; LiveContainer and standalone results can differ.

## Source and licenses

The other release files are for source access, rebuilding, and download verification:

- Download both `Iridium-corresponding-source.tar.gz.part01` and `.part02` for the complete matching source package.
- `Iridium-source-guide.zip` contains license notices and build/relink instructions.
- `SHA256SUMS` verifies all four files above, including the IPA.

Download all five release files into one folder, then run:

```sh
shasum -a 256 -c SHA256SUMS
cat Iridium-corresponding-source.tar.gz.part01 Iridium-corresponding-source.tar.gz.part02 > Iridium-corresponding-source.tar.gz
```

The source guide includes the checksum for the assembled archive and rebuild instructions. GitHub's automatic repository ZIP does not contain all required dependency sources.
