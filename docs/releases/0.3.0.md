# Iridium 0.3.0

Experimental review version. This is an unpublished draft, not a release announcement.

## Download

No published 0.3.0 asset is identified here. Exact review build runs and package
checks are tracked in [PR #92](https://github.com/intraducine/iridium/pull/92).
Review IPAs need recipient signing. The app requires iOS/iPadOS 18+, owned game
files, and JIT for Windows and most console engines. PSP also has an interpreter.

## Install

Back up saves and keep existing app data. Sign the app, helpers, and frameworks
with a compatible tool. LiveContainer runs need its host's supported JIT route;
external attachment alone does not prepare Iridium's shared executable memory.
Keep increased-memory-limit in the final signature and profile; the anonymous
carrier grants no installation or provisioning rights. Configure JIT Setup, then
use Add Game for files, bulk imports, or stores. Do not delete the old game copy
until its saves work after migration.

## What's new

- One library and shared player for Windows, GB/GBC, PSP, GameCube/Wii, 3DS,
  PS2, and Dreamcast/arcade, with modular engine pins and per-game controls.
- Import folders for games, archives, and pairing files. Existing and new managed
  games use Games folders; IDs, saves, and installed 3DS storage owners stay intact.
- Steam, GOG, Epic Games, EA, and itch.io routes, with store uninstall and deleted
  folder handling. Partial installs remain available for supported repair.
- Smooth cover, text, and backdrop changes; shared loading status and live app
  memory use; default volume and haptics; a separate saved setup marker.
- Reviewed Madeira 0.2.0/main updates and reusable Windows sessions. JIT prepares
  only the requested arena and checks page responses in bounded batches with
  complete 64-bit addresses. Menu sound effects remain outside this integration.

## Known issues

Built-in JIT needs the owned helper and a supported standalone installation.
Older external helpers use safe per-page preparation. Windows settings read at
host startup and uncertain cleanup can require an app restart. Console states
can be incompatible after engine updates. Keep ordinary in-game saves.

New JIT startup times, Windows rotation under native load, repeated engine
switches, PS2/Dreamcast audio and pacing, store sign-in/download/repair paths, and
physical reinstall behavior still need tests on the exact new device build.
Source, simulator, and package checks do not establish gameplay or performance.
